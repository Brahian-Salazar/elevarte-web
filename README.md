# ElevArte — Vuela sin límites

Sitio web de **ElevArte**, un proyecto artístico y de bienestar dedicado a la danza aérea, el movimiento corporal y las experiencias artísticas para eventos y empresas.

🌐 **Visita el sitio web:** https://elevarte-web-five.vercel.app/

## ✨ Descripción

ElevArte conecta el arte, el movimiento y el bienestar mediante clases, entrenamientos y espectáculos artísticos.

Este proyecto consiste en una página web comercial diseñada para presentar los servicios de la marca, destacar su identidad visual y facilitar el contacto con potenciales estudiantes y clientes.

## 🎯 Objetivos

- Presentar la identidad y propuesta de valor de ElevArte.
- Dar visibilidad a sus disciplinas y servicios.
- Exhibir contenido visual relacionado con sus actividades.
- Facilitar el contacto con personas interesadas.
- Proporcionar una experiencia adaptable a dispositivos móviles.

## 🩰 Servicios

La propuesta de ElevArte incluye:

- **Academia y entrenamiento:** telas aéreas, lira aérea, pole sport, flexibilidad y acondicionamiento físico.
- **Clases personalizadas:** sesiones individuales y para parejas.
- **Shows y eventos:** espectáculos artísticos, presentaciones aéreas y animación.
- **Bienestar corporativo:** pausas activas y actividades de movimiento y bienestar.

Consulta el sitio web para conocer la información disponible sobre los servicios.

## 💻 Instalación y ejecución local

Si el proyecto utiliza Node.js y npm, puedes seguir estos pasos:

1. Clona el repositorio:

   ```bash
   git clone URL_DE_TU_REPOSITORIO
   ```

2. Accede a la carpeta del proyecto:

   ```bash
   cd nombre-del-proyecto
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Ejecuta el servidor de desarrollo según la configuración del proyecto:

   ```bash
   npm run dev
   ```

Verifica los comandos disponibles en el archivo `package.json` antes de ejecutar estos pasos.
